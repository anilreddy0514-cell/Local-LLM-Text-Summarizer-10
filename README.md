# Shortform: Local Text Summarizer

Shortform is a lightweight text summarization app built with FastAPI and Ollama. Paste an article, notes, or another passage into the browser interface and Shortform returns a concise summary generated by a locally running language model. The default model is TinyLlama.

The app is designed to keep text on your machine: the browser sends text to the FastAPI app, which forwards it to the Ollama server configured by `OLLAMA_URL`. No external summarization API is used. If you configure Ollama to run on another host, that host will receive the text.

## Features

- Browser interface with a live character count, loading status, and copy-to-clipboard action.
- Input validation for blank text and a maximum input length of 20,000 characters.
- Clear error messages for Ollama connection failures, missing models, timeouts, and invalid responses.
- Configurable Ollama server, model, and request timeout.

## API

- `GET /`: serves the summarizer interface.
- `GET /health`: reports app status and the configured model.
- `POST /api/summarize`: accepts `{"text": "..."}` and returns `{"summary": "..."}`.
- `GET /docs`: interactive API documentation provided by FastAPI.

## Setup

Install Conda (Miniforge is a good macOS option) if it is not already available, then create and activate the environment:

```sh
conda env create -f environment.yml
conda activate local-text-summarizer
```

Install the default model and ensure Ollama is running:

```sh
ollama pull tinyllama
ollama serve
```

If Ollama is already running as a background service, you do not need to start `ollama serve` again. To use another model already pulled locally, set `OLLAMA_MODEL` to its Ollama model name (for example, `llama3.1:8b`).

## Run

```sh
uvicorn app.main:app --reload
```

Open <http://127.0.0.1:8000>. API docs are available at <http://127.0.0.1:8000/docs>.

## Configuration

- `OLLAMA_URL`: Ollama base URL; defaults to `http://localhost:11434`.
- `OLLAMA_MODEL`: model name; defaults to `tinyllama`.
- `OLLAMA_TIMEOUT`: request timeout in seconds; defaults to `120`.

Input is limited to 20,000 characters. Run tests with `pytest`.
